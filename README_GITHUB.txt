SOMBRAS DE DIANA — versão GitHub Pages

Arquivos principais:
- index.html
- assets/

Como publicar:
1. No repositório GitHub, envie index.html e a pasta assets completa.
2. Vá em Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /root.
6. Salve e aguarde o link público.

Importante:
- Esta versão é própria para GitHub Pages.
- O HTML foi aliviado para evitar o erro de upload de arquivo maior que 25MB.
- As músicas e imagens ficam como arquivos externos em assets/.
